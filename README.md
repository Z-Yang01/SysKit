# SysKit 系统工具箱

一个针对 Windows 11「已连接但显示无网络 / 网络时好时坏」问题的诊断修复工具，
并扩展为覆盖网络监控、网络工具与系统助手的桌面工具箱。
**Rust + Tauri 2 + React + TypeScript** 实现，托盘常驻、自动监控、逐级修复。

> 前身为 NetTool（更早是 Python+PySide6 实现，已退役归档：见文末「Python 版」）。
> 显示名与内部标识均为 SysKit（数据目录 `%APPDATA%\SysKit` / `%LOCALAPPDATA%\SysKit`）。

**源码、构建、开发与测试全部在 [`app-rs/`](app-rs/README.md)**——本文件只做产品概览。

## 功能总览（侧边栏导航）

- **🏠 概览**：网卡一览 + 大字状态徽章 + 一键体检 + 实时速率面板
- **📈 网络监控**：网关/公网延迟曲线、实时上下行速率、WiFi 信号历史、每日流量累计、断网/恢复事件时间线；托盘悬浮实时速率；断网/恢复声音提醒
- **📶 WiFi 工具**：周边 AP 扫描、信道占用分析与推荐信道、WiFi 二维码分享、已存密码查看
- **🔍 诊断**：15 项逐条检查（NlaSvc / 幽灵路由 / 静态 DNS / **系统代理残留** / NCSI / 授权拦截等），双击未通过项直接修复
- **🔧 修复**：一键快速/深度/重置组合 + 19 个单项动作（按风险分级）+ WiFi 专区（MAC 随机化开关/重连）+ 修复记录
- **⚡ 工具箱**：速度测试、局域网设备发现、**端口占用查看器（找进程/结束进程）**、DNS/子网计算、持续 ping 与路由追踪、**Hosts 编辑器**、DNS 测速（推荐可一键应用、历史趋势对比）、**应用联网控制**（Windows 防火墙出站块）、**磁盘空间分析**（目录占用树/类型分布/大文件排行，删除仅移入回收站）、**剪贴板历史**（文本/图片/文件/HTML，搜索+分类+置顶，规则引擎）
- **🧰 系统助手**：性能监控（CPU/内存/磁盘曲线 + Top 进程）、启动项管理、电池健康、白名单垃圾清理、**场景模式**（办公/游戏一键切换）
- **📶 二维码识别**（工具箱）：识别截图/图片里的二维码——链接直接打开、WiFi 码拆解出 SSID/密码（复制走敏感通道）；剪贴板历史图片条目一键识别。全程本机完成不联网
- **📊 应用流量**（网络监控）：按进程实时统计收发字节（ETW 内核采集），今天/本周/本月 × 应用搜索 × Top 15 占比条；数据本机留存 365 天
- **📈 网络质量**（网络监控）：网关/公网延迟曲线、丢包率、DNS 解析耗时趋势——后台 10 秒一轮探测，近 60 分钟/48 小时趋势图，数据本机留存 365 天（设置页可关）；可选质量告警：公网丢包/延迟超阈值时托盘通知并记入事件时间线，恢复也通知（10 分钟冷却）
- **🔐 密码库**：网站/账号两级密码管理（SQLite + AES-256-GCM 密文落盘），主密码可选（未设时 Windows DPAPI 免密保护）；TOTP 动态码；复制的密码不进剪贴板历史、不进系统 Win+V 历史、不上云剪贴板，25 秒自动清空
- **⌘ 命令面板**（全局热键 `Ctrl+Alt+K` / 应用内 `Ctrl+K`）：页面与工具跳转、快捷诊断修复、剪贴板最近条目回填、密码库全局直达、`ping 主机` / `dns 域名`、自定义命令
- **⚙ 设置 / 📋 日志**：自动修复策略、声音提醒、深色模式、开机自启、剪贴板/密码库/命令面板选项；双日志 7 天自动清理

## 这个工具解决什么问题

Windows 判断「有没有网」依赖 **NCSI 探测**，而探测由 **NlaSvc（网络位置感知）服务**执行。
服务被优化软件改成手动、持久路由指向失效网关、网卡残留静态 DNS、网卡被允许省电关机、
MAC 随机化与公寓/企业 AP 授权冲突、NCSI 探测配置被改——任一环节出问题都会出现
「WiFi 明明连上，系统却显示无网络」。SysKit 的 15 项诊断逐条定位上述病灶，
双击即修复（改前自动备份原值）；后台每 30 秒探测，连续失败按固定梯度自动修复，
改配置类动作**永不自动执行**、只弹建议。

> 公寓/酒店等「按设备授权」的网络若 AP 侧从未授权本机（网关 ping 全丢），
> 需要在运营方 App/认证页重新授权设备——诊断会明确告诉你这种情况。

## 使用

### 安装

- **安装包**：`app-rs` 下 `npx tauri build` 产出 NSIS 安装器（`src-tauri/target/release/bundle/nsis/`），
  可选安装位置、桌面快捷方式、开机自启，默认**便携模式**（数据存安装目录 `data\`，整体拷贝即迁移），
  自动写入卸载信息（卸载不删除用户数据）
- **便携使用**：直接运行 `SysKit.exe` 即可（无 data 目录时数据回退 `%APPDATA%`）
- 版本号见 [`app-rs/src-tauri/tauri.conf.json`](app-rs/src-tauri/tauri.conf.json) 的 `version`
  （当前 1.2.0，窗口标题与设置页显示）

### 日常使用

- **概览页**：网卡一览 + 大字判定（正常 / NCSI 误报 / DNS 异常 / 断网）+ 一键体检
- **诊断页**：15 项逐条检查，双击未通过项可直接执行建议修复
- **修复页**：一键组合（执行中可「中止」）+ 19 个单项动作 + WiFi 专区
- **托盘**：图标颜色 = 网络状态（绿正常 / 黄连上无网 / 灰离线），悬浮显示实时速率；
  右键菜单直达各页面与快捷粘贴
- 全部动作留痕于日志页；备份写入 `%LOCALAPPDATA%\SysKit\backup\<时间戳>\`，
  日志在 `%LOCALAPPDATA%\SysKit\logs\`（便携模式在 `<安装目录>\data\` 下）
